# 민감도 매트릭스 — 자산군(행) × 팩터(열)

각 셀: **(1) 방향** / **(2) 계산식 또는 정성 경로** / **(3) 주의점**.
기호: Δy = 금리 변화(소수, 100bp = 0.01), D_mod = 수정듀레이션, C = 컨벡시티, SD = 스프레드 듀레이션, Δs = 스프레드 변화.
방향은 "팩터 상승(+) 시 자산가치"의 방향. calc_impact.py가 실제로 계산하는 셀은 ✅, 정성 서술만 하는 셀은 📝.
가정값(기본 듀레이션, 캡레이트, LGD, 베타 등)은 `config/assumptions.yaml`에 있으며 모두 "가정"이다.

## 1. 원화 채권 (국공채·특수채·금융채·회사채)

| 팩터 | (1) 방향 | (2) 계산식 / 경로 | (3) 주의점 |
|---|---|---|---|
| ktb_3y/10y/30y_bp ✅ | 금리↑ → 가치↓ | ΔP/P ≈ −D_mod·Δy + ½·C·Δy². 금리 팩터는 듀레이션에 맞춰 3·10·30년 선형 보간 (D≤3 → 3Y, D≥30 → 30Y) | AC(상각후원가) 분류분은 손익·자본에 즉시 반영되지 않음(IFRS9). 공정가치 변동이 실제 회계에 미치는 영향은 계정 분류 확인 필요 |
| kr_aa_spread_bp ✅ | 확대 → 가치↓ | 회사채·금융채(AA 이상): −SD·Δs. SD 미공시 시 SD = D_mod(가정) | 국공채는 스프레드 영향 0. 특수채·금융채는 `assumptions.spread_beta`의 비율만 적용(가정) |
| kr_bbb_spread_bp ✅ | 확대 → 가치↓ | `credit_grade`가 BBB 이하인 회사채에 −SD·Δs | 보험사 BBB 이하 보유 비중은 작음. 등급분포 미공시 시 전량 AA로 가정(추정 표시) |
| kr_base_rate_bp 📝 | 간접 | 기준금리 → 단기금리 → 커브 앞단. 직접 계산은 ktb_3y에 반영된 것으로 본다 | 이중 계산 금지 |

## 10. 보험사 특유 사항

| 항목 | (1) 방향 | (2) 계산식 / 경로 | (3) 주의점 |
|---|---|---|---|
| 부채 듀레이션 갭 ✅ | 금리↓ → 부채↑ | 순자산 영향 ΔNAV ≈ −(D_A·A − D_L·L)·Δy (Δy = `assumptions.alm_rate_factor`, 기본 ktb_10y_bp). D_L > D_A·A/L이면 금리 하락이 순자산에 불리 | IFRS17 부채 할인율은 무위험 + 유동성 프리미엄이며 장기 구간은 최종관찰만기 이후 장기선도금리(LTFR) 수렴 → 국고채 30년과 1:1이 아님. CSM이 일부 흡수 |
| K-ICS 시장위험 📝 | | 금리위험(듀레이션 갭), 주식위험, 부동산위험, 외환위험, 자산집중위험 요구자본. 자산 재분류(예: 주식 → 인프라 적격, 수익증권 look-through)로 위험계수 변화 | **위험계수는 실제 감독기준(보험업감독업무시행세칙 별표)을 확인해 `config/assumptions.yaml`의 `kics.risk_factors`에 입력하기 전까지 정성 서술만 한다.** 숫자 추정 금지 |
| 해지·유동성 📝 | 금리 급등 → 해지 증가 | 저축성 상품 해지 → 유동성 수요 → 자산 매각 손실 | 손보는 생보보다 영향 작음 |
