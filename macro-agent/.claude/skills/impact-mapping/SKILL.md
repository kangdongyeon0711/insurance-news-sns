# impact-mapping

CLAUDE.md의 원칙을 따른다. 계산 가능한 것은 `scripts/calc_impact.py` 결과를 인용하고, 이 스킬은 **계산이 포착하지 못하는 경로를 정성적으로 보완**하는 데 쓴다.

## 언제 쓰나
- `/portfolio-impact` 6단계: calc_impact 결과를 자산군별로 해석할 때
- 매크로 브리프의 "크로스에셋 시사점"을 쓸 때
- 리밸런싱 제안의 근거·실행 리스크를 쓸 때

## 사용법
1. `sensitivity_matrix.md`에서 해당 자산군(행) × 팩터(열) 셀을 찾는다: (1) 방향, (2) 계산식 또는 정성 경로, (3) 주의점.
2. calc_impact가 계산한 항목은 숫자를 그대로 인용(`reports/tmp/*_impact.json`)하고, 셀의 "주의점"으로 한계를 단다.
3. calc_impact가 0이거나 계산하지 않은 경로(예: 유가 → 물가 → 금리, PF 충당금의 손익 인식 시차, 대체투자 평가 지연, 부채 할인율 효과, K-ICS 요구자본)는 `[판단]` 태그로 서술한다. 숫자를 새로 만들지 말고, 필요하면 "정성: 부정적/중립/긍정적, 규모 미확인"으로 쓴다.
4. 보험사 특유 사항(듀레이션 갭, K-ICS)은 반드시 한 단락 이상 다룬다. K-ICS 위험계수는 `config/assumptions.yaml`의 `kics`에 실제 감독 기준을 확인해 입력하기 전까지 **정성 서술만** 한다.

## 전달 경로 요약 (상세는 sensitivity_matrix.md)
```
한미 단기금리차 ─▶ 원/달러 ─▶ 해외자산 비헤지분 평가 / 헤지분 헤지비용 ─▶ 해외채 실질 수익률
유가 ─▶ 국내외 물가 ─▶ 기준금리 경로 ─▶ 국고채 커브 ─▶ 채권 평가 + 보험부채 할인율
국고채 ─▶ 크레딧 스프레드(수급) ─▶ 회사채·금융채
금리 ─▶ 캡레이트·할인율 ─▶ 부동산·인프라 평가 (시차: 감정평가 분기~반기)
금리·분양 ─▶ PF 사업성 ─▶ 손실률·충당금 ─▶ 대출 손익
경기·금리 ─▶ 부도율 ─▶ 사모대출 손실 (변동금리 이자 수익과 상쇄)
금리 하락 ─▶ 부채 평가 증가 (D_L > D_A이면 순자산 감소) ─▶ K-ICS 비율
```
