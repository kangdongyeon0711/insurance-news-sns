## 크로스에셋 시사점

[판단] 아래는 impact-mapping 스킬의 전달 경로 기준 연결이며, 시나리오 수치는 각 topic의 factor_shocks를 인용한 것이다. topic별 시나리오 확률이 서로 달라 아래 연결은 방향의 일관성만 본다.

1. **한미 금리차 → 환율 → 해외채 헤지비용**: 장기 Base에서 한은은 +50bp(`kr_base_rate_bp`), 연준은 −50bp(`us_ffr_bp`)로, 한미 단기금리차가 약 100bp 좁혀진다. 헤지비용은 대략 단기금리차를 따르므로 −100bp 안팎이 일관적이다. 그러나 fx_krwusd의 Base `fx_hedge_cost_bp`는 −20bp로 보수적이다. **⚠ topic 간 불일치 — 다음 주 fx-commodity 재검토 대상.** 헤지비용이 내리면 보험사 해외채의 헤지 후 수익률이 좋아지므로 해외채 비중 유지·확대 근거가 된다.
2. **유가 → 물가 → 금리**: Brent 고점권(116.72달러, 10-23)은 한미 CPI에 상방 압력을 주며, 단기 추가 인상 1회 시나리오(양국 +25bp)의 주된 근거다. Bear에서도 유가(+15%), 국고채 10년(+50bp), UST 10년(+60bp)이 모두 같은 방향이다. 다만 oil Bear는 0.3, 국채 Bear는 0.25로 topic별 확률이 다르다.
3. **금리 → 캡레이트·할인율 → 부동산·인프라**: 미국은 UST 10년 Base −25bp와 캡레이트 −15bp가 같은 방향이다(전이율 약 0.6). 한국은 국고채 10년 Base가 +10bp인데 캡레이트·인프라 할인율은 0bp다. kr-alternatives가 국고채 보합을 가정하고 작성했기 때문이다. 소폭 상방(+5bp 내외)이 더 일관적이나 규모가 작아 이번 주는 그대로 둔다.
4. **크레딧 → 사모대출**: US HY Base +70bp·Bear +300bp와 Private Credit 부도율 Bear +3%p가 같은 방향이다. 변동금리 이자수익(FFR 인상 시 +)과 부도 손실이 상쇄되는 구조여서, PD 자산은 금리보다 신용 사이클에 더 민감하다.
5. **커브 → 보험 ALM**: 국고채 커브 Base는 베어 플래트닝이다(3년 +20, 10년 +10, 30년 +5bp). 초장기 구간 상승폭이 작아 부채 할인율 상승도 작다. 따라서 듀레이션 갭이 음(−)인 보험사(부채 듀레이션이 더 긴 경우)가 금리 상승으로 얻는 순자산 이익은 제한적이다.
