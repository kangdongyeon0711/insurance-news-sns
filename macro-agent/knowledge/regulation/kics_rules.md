# K-ICS 규칙 요약 — 포트폴리오 추천용

- 출처: 보험연구원 연구보고서 2024-14, Ⅱ장 "K-ICS 주요 내용"(보고서 p.7–24). 원문 PDF: `processed/regulation/보험연구원_연구보고서2024-14_K-ICS주요내용.pdf`(사용자 제공, 2026-11-21). 근거 법규: 보험업 감독업무 시행세칙 [별표 22].
- 이 문서는 2024년 기준 요약이다. 이후 개정(예: 2024-11 보험개혁회의 후속 조치, 할인율·해지위험 개정)은 반영되지 않았을 수 있다 → 수치를 쓸 때 "보고서 기준(2024)"이라고 밝힌다.
- **이 자료에 없는 것: 신용위험액 위험계수(채권·대출의 등급·만기별 계수), 금리 충격 시나리오의 만기별 충격 폭, 무등급 익스포저 계수.** 이 값들은 여전히 미확인이며 `config/yield_assumptions*.yaml`의 신용 계수는 가정이다.

## 1. 비율과 감독 조치 (p.7–8)
- K-ICS 비율 = 가용자본(지급여력금액) ÷ 요구자본(지급여력기준금액), 법정 최소 100%.
- 적기시정조치: 50~100% 경영개선권고, 0~50% 경영개선요구, 0% 미만 경영개선명령.
- RBC 대비: 모든 자산·부채 시가평가, 신뢰수준 99.0% → 99.5%, 충격시나리오 방식(일반손보·신용·운영은 위험계수 방식).

## 2. 자산·부채 평가 (p.9)
- FVOCI·AC 구분 없이 **모든 자산을 시가 평가**(대출·부동산 포함). → AC 채권의 평가손익도 K-ICS 순자산에 반영된다.
- 보험부채 = 현행추정부채(무위험 수익률 할인) + 위험마진(생명·장기 85백분위, 일반 65백분위 − 평균, 신뢰수준법).
- 조정준비금 = 건전성 순자산 − 감독회계 자본항목(CSM, AC 자산 공정가치 평가액 등 포함).

## 3. 가용자본 (p.10–13)
- 기본자본: 보통주, 기본자본 요건 충족 자본증권, 이익잉여금, 자본조정, 기타포괄손익누계액, 조정준비금 − 손실흡수 제한 항목.
- 보완자본 한도: **총요구자본의 50%**(RBC는 기본자본의 100%). 경기순응성 완화 목적.
- 자본증권 인정 한도:

| 구분 | 조건 | 자본 구분 | 한도 |
|---|---|---|---|
| 신종자본증권 | 비조건부, Step-up 없음 | 기본자본 | 요구자본 10% |
| 신종자본증권 | 조건부, Step-up 없음 | 기본자본 | 요구자본 15% |
| 신종자본증권 | Step-up 있음 | 보완자본 | 요구자본 50%(보완 합계) |
| 후순위채 | 조건 무관 | 보완자본 | 요구자본 50%(보완 합계) |

- 순이연법인세자산·사외적립 퇴직연금자산 50%는 합산 요구자본 15% 이내에서 보완자본.
- 해약환급금 부족분 상당액 중 해약환급금준비금 초과분: 금리 상승 시 발생, 보완자본(한도 미적용).
- **[운용 함의]** 자본증권 발행으로 비율을 올리는 데는 요구자본 대비 한도가 있다(기본 10~15%, 보완 합계 50%).

## 4. 요구자본 구조 (p.13–15)
- 총요구자본 = 기본요구자본 − 법인세조정액 + 기타요구자본(비연결 종속·관계회사: 업권별 규제 또는 총자산 8% 대용치).
- 기본요구자본: 생명·장기손해, 일반손해, 시장, 신용 4개 위험을 상관계수로 합산 + 운영위험(상관 미적용, 단순 가산).

| 상관계수 | 생명·장기 | 일반손해 | 시장 | 신용 |
|---|---|---|---|---|
| 생명·장기 | 1 | | | |
| 일반손해 | 0 | 1 | | |
| 시장 | 0.25 | 0.25 | 1 | |
| 신용 | 0.25 | 0.25 | 0.25 | 1 |

- **[운용 함의]** 시장·신용 상관이 0.25라 분산효과가 크다. 시장위험 1원 증가의 한계 요구자본 기여는 1원보다 작다(현재 위험 구성에 따라 다름). `yield_assumptions`의 diversification 0.7은 이 구조의 근사(가정).

## 5. 시장위험 (p.17–20)
하위위험 상관계수(자산집중은 분산효과 없음):

| | 금리 | 주식 | 부동산 | 외환 | 자산집중 |
|---|---|---|---|---|---|
| 금리 | 1 | | | | |
| 주식 | 0.25 | 1 | | | |
| 부동산 | 0.25 | 0.25 | 1 | | |
| 외환 | 0.25 | **−0.25** | 0.25 | 1 | |
| 자산집중 | 0 | 0 | 0 | 0 | 1 |

### 금리위험
- 5개 시나리오(상승·하락·평탄·경사·평균회귀)를 자산·부채 모두에 적용.
- 금리위험액 = 평균회귀 금액 + max(상승, 하락) + max(평탄, 경사).
- **[운용 함의]** RBC처럼 듀레이션 갭만 맞춰서는 부족하다. **만기별 현금흐름(키레이트)까지 부채와 맞아야** 위험액이 줄어든다. 평탄·경사 시나리오가 있으므로 장기 부채에는 초장기물(30·50년)로 커브 끝단까지 매칭해야 한다.
- 시나리오별 충격 폭(만기별 bp)은 이 자료에 없다(미확인).

### 주식위험 충격(가격 하락률)

| 선진시장 상장(국내 상장 포함) | 신흥시장 상장 | 우선주 | 인프라 주식 | 장기보유 주식 | 기타 주식(비상장·PEF 등) |
|---|---|---|---|---|---|
| 35% | 48% | 신용등급별 4~49% | 20% | 20% | **49%** |

- 장기보유주식: 선진시장 상장주식 중 10년 이상 보유 계획 문서화 등 요건 충족 시 35% → 20%.
- 파생상품·변액보험은 주가 변동성 충격도 반영.
- **[운용 함의]** 같은 인프라라도 지분형은 20%로 PE(49%)보다 훨씬 가볍다. 전략적 상장지분은 장기보유 요건 검토로 요구자본을 크게 줄일 수 있다.

### 부동산위험
- 부동산 가격 25% 하락(의무보유부동산 20%). 직접·간접(펀드) 모두 해당.

### 외환위험
- max(환율 하락, 환율 상승) 위험액 + 가격변동위험액. 35개국 통화 충격, 순자산이 감소하는 통화끼리 상관 0.5.
- 가격변동위험액 = 환 파생 갱신 시 위험경감효과 인정분.
- **[운용 함의]** 주식-외환 상관이 −0.25라 미헤지 해외주식은 분산효과가 있다. 해외채는 통상 헤지하므로 외환위험은 작고 갱신(롤오버) 위험이 남는다.

### 자산집중위험 (p.19–20)
| 구분 | 신용등급 | 한도(총자산 대비) | 위험계수(초과분) |
|---|---|---|---|
| 거래상대방 | 1·2 | 4% | 15% |
| 거래상대방 | 3·4 | 3% | 25% |
| 거래상대방 | 5·6·7 | 1.5% | 50% |
| 부동산 | 개별(250m 내 근접 포함) | 6% | 20% |
| 부동산 | 전체 | 25% | 20% |

- 대상: 예치금·주식·채권·신용공여·파생 등 거래상대방 익스포저와 부동산. 특별계정, 중앙정부 등 신용 계수 0인 상대방은 제외.
- 예시: 총자산 10조에서 1등급 주식 1조 → 주식위험 3,500억 + 한도(4,000억) 초과 6,000억 × 15% = 900억 → 4,400억(자산집중은 분산효과 없음).
- **[운용 함의]** 단일 계열·단일 차주(예: 대형 인수금융, 단일 빌딩) 집중은 추가 부담이 생긴다. 저등급(5등급 이하)은 총자산 1.5%부터 50%가 붙는다.

## 6. 생명·장기손해보험위험 (p.15–17, 참고)
- 충격: 사망률 +12.5%, 장수(사망률 −17.5%), 장해·질병(정액 위험률 +13%, 실손 +10%), 장기재물·기타 +16%, 해지(옵션행사율 ±35% 또는 대량해지 저축성 35%·보장성 25%), 사업비(+10%, 인플레이션 +1%p), 대재해(위험계수).
- 운용과 직접 관련은 적으나 해지 위험(대량해지)이 클수록 유동성 자산 보유 필요성이 커진다.

## 7. 경과조치 (p.20–24)
| 종류 | 구분 | 방식 | 2026년 적용 |
|---|---|---|---|
| 제도 시행 전 발행 자본증권 인정(TFI) | 공통 | 2032년 말까지 인정, 기본자본은 요구자본 15%까지 | 적용 |
| 시가평가 자본감소분 점진 인식(TAC) | 선택 | 감소분 × 적용비율(2023년 100% → 매년 −10%p) | 70% 가산 |
| 신규 보험위험(장수·해지·사업비·대재해) 점진 인식(TIR) | 선택 | 위험액 × 적용비율(2023년 0% → 매년 +10%p) | 30% 인식 |
| 주식위험 증가분 점진 인식(TER) | 선택 | RBC 위험액이 K-ICS의 60% 이하일 때, 2023년 60% → 매년 +4%p | 72% 인식 |
| 금리위험 증가분 점진 인식(TIRR) | 선택 | 위 주식과 같은 방식 | 72% 인식 |

- 신청 현황(2023): 19개사(생보 12, 손보 6, 재보 1). 신규 보험위험은 19개사 모두, 주식 12개사, 금리 8개사.
- 적용 회사는 경과조치 전후 비율 공시, 배당 제한 등 관리.
- **[운용 함의]** 경과조치 적용 회사(예: 교보생명 — TFI·TIR·TER, 공시 p.13)는 해마다 인식 비율이 올라가 **경과조치 후 비율이 자연 하락**한다(TIR +10%p/년, TER +4%p/년). 추천안의 K-ICS 하한은 경과조치 **전** 비율 기준으로 보는 것이 보수적이다.

## 8. 엔진·가정에 반영한 것 / 남은 공백
- `config/yield_assumptions.yaml`(+ 교보생명·DB손해보험 사본): 대체-PE 계수 0.48 → **0.49**(기타 주식). 주식 0.35, 부동산 0.25는 이 자료로 확인. (KB손해보험 사본은 2026-11-01 리포트 재현을 위해 그대로 둠.)
- 인프라 지분형은 20% — 현재 대체-인프라 계수 [0.05, 0.20]은 대출형~지분형 범위로 유지.
- 남은 공백: 신용위험 계수(채권·대출 등급·만기별), 무등급·담보 경감, PF 특례, 금리 시나리오 만기별 충격 폭 → 감독규정 [별표 22] 원문 필요.
